# LINE · Art media

Buka `index.html` langsung di browser. Tidak perlu instalasi atau server.

Halaman, CSS, JavaScript, gambar, dan font ada di `public/files/`. Edit file HTML dan CSS langsung, lalu refresh browser. `index.html` adalah halaman utama. Folder `assets/` berisi aset asli; `scripts/` menyimpan salinan template dan kode dari prototipe sebelumnya sebagai referensi.

Harga, minimum order, dan logo klien perlu diganti dengan data yang disetujui sebelum peluncuran. Nomor WhatsApp bisnis belum diisi, sehingga konsultasi masih membuka pratinjau pesan lokal. Halaman menggunakan `noindex,nofollow`; pengindeksan dan domain perlu disiapkan sebelum tayang.
